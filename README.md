# Коллекция Интерактивных Веб-Приложений

Коллекция из восьми современных одностраничных веб-приложений, каждое в отдельном HTML-файле. Все приложения полностью функциональны, не требуют внешних зависимостей (кроме CDN для библиотек) и имеют русскоязычный интерфейс.

## 📁 Проекты

### 1. 🎮 Побег из Лабиринта (`escape-the-maze/`)
**Цель:** Навигация от старта до финиша в случайно сгенерированном лабиринте.

**Особенности:**
- Управление стрелками клавиатуры
- Таймер с точностью до десятых секунды
- Счётчик шагов
- Бонус за кратчайший путь (автоматический расчёт оптимального маршрута)
- Кнопка перезапуска
- Современный тёмный интерфейс с визуально чёткими стенами лабиринта
- Анимированный аватар игрока

**Технологии:** Чистый HTML, CSS, JavaScript (алгоритм генерации лабиринта: рекурсивный бэктрекинг)

---

### 2. 📊 Площадка для Визуализации Данных (`data-visualization-playground/`)
**Цель:** Загрузка CSV-файлов и генерация настраиваемых графиков.

**Особенности:**
- Загрузка CSV через перетаскивание или выбор файла
- Автоматическое определение разделителя
- Выбор типа графика: линейный, столбчатый, круговой, кольцевой, радарный
- Настройка колонок для меток и датасетов
- Кастомизация цветов для каждого датасета
- Экспорт графика как PNG изображения
- Данные по умолчанию для демонстрации
- Современный интерфейс с тёмной темой и фиолетово-розовыми акцентами

**Технологии:** HTML, CSS, JavaScript, Chart.js (CDN)

---

### 3. 🗺️ Поток Путешествия Клиента (`customer-journey-flow/`)
**Цель:** Визуализация этапов путешествия клиента от осведомленности до покупки.

**Особенности:**
- Редактируемые этапы (двойной клик по заголовку)
- Перетаскивание этапов мышью
- Соединение этапов через ручки (синие кружки)
- Изогнутые линии соединений со стрелками направления
- Автоматическая раскладка этапов
- Экспорт диаграммы в JSON
- Сброс и добавление новых этапов
- Чистый диаграммный интерфейс с сеткой в фоне

**Технологии:** HTML, CSS, JavaScript, SVG для соединений

---

### 4. 🎨 Совпадение Цветов (`color-match/`)
**Цель:** Быстрая игра на реакцию - нажать кнопку с цветом, соответствующим цвету текста (не значению слова).

**Особенности:**
- Случайные комбинации слов и цветов
- Счёт на основе правильных ответов
- Таймер на 30 секунд
- Крупная типографика для лучшей читаемости
- Цветные кнопки с плавными анимациями нажатия
- Адаптивный дизайн для мобильных устройств
- Тёмная тема с яркими цветовыми акцентами

**Технологии:** Чистый HTML, CSS, JavaScript

---

### 5. 🧮 Тренировка по Математике (`math-practice-drills/`)
**Цель:** Улучшение скорости и точности решения математических задач.

**Особенности:**
- Таймер на каждую задачу с настраиваемым временем (5-30 секунд)
- Четыре уровня сложности: лёгкий, средний, сложный, эксперт
- Отслеживание правильных и неправильных ответов
- Расчёт точности в реальном времени
- Автоматическая генерация задач в зависимости от уровня сложности
- Минималистичный интерфейс с крупным, читаемым текстом
- Мгновенная проверка ответов
- Экран результатов с подробной статистикой
- Поддержка операций: сложение, вычитание, умножение, деление
- Тёмная тема с удобными выпадающими списками

**Технологии:** Чистый HTML, CSS, JavaScript

---

### 6. 🎵 Тренажёр по Теории Музыки (`music-theory-trainer/`)
**Цель:** Обучение нотам, гаммам и аккордам.

**Особенности:**
- Интерактивное пианино с визуальными клавишами и звуком через Web Audio API
- Управление мышью и клавиатурой компьютера (Z-M для белых клавиш, цифры для чёрных)
- Лаборатория гамм: мажорные, минорные, пентатоника, блюзовые
- Лаборатория аккордов: мажорные, минорные, уменьшённые, увеличенные, sus2, sus4, септаккорды
- Визуальная разметка клавиш для гамм и аккордов
- Воспроизведение гамм и аккордов (блоком и арпеджио)
- Тренировка слуха: упражнения на распознавание нот
- Настройка диапазона пианино, громкости и сустейна
- Музыкальная тематика интерфейса с градиентным фоном
- Адаптивный дизайн для различных устройств

**Технологии:** HTML, CSS, JavaScript, Web Audio API

---

### 7. 📋 Маленький Канбан (`tiny-kanban/`)
**Цель:** Организация рабочего процесса "Сделать → В работе → Готово".

**Особенности:**
- Перетаскивание карточек между колонками и изменение порядка
- Лимиты WIP (Work In Progress) для каждой колонки с визуальными предупреждениями
- Цветовая индикация приоритетов: Критический (красный), Высокий (оранжевый), Средний (жёлтый), Низкий (зелёный)
- Назначение задач на исполнителей с отображением меток
- Поиск и фильтрация по названию, исполнителям (@alice) и приоритетам
- Редактирование задач через модальное окно
- Удаление задач с подтверждением
- Быстрое добавление задач с выбором приоритета и исполнителей
- Функция "Стендап" для быстрого обзора задач в работе и следующих задач
- Очистка колонки "Готово"
- Сохранение данных в localStorage
- Тёмная тема, оптимизированная для ежедневных стендапов
- Компактный интерфейс с читаемым шрифтом

**Технологии:** HTML, CSS, JavaScript, LocalStorage API

## 🚀 Использование

Каждое приложение находится в своей папке и представляет собой один HTML-файл. Просто откройте `index.html` в современном веб-браузере.

### Требования
- Современный браузер с поддержкой ES6+ JavaScript
- Для "Площадки для Визуализации Данных" требуется подключение к интернету (загрузка Chart.js через CDN)

### Запуск
```bash
# Откройте любой из проектов в браузере:
# - escape-the-maze/index.html
# - data-visualization-playground/index.html
# - customer-journey-flow/index.html
# - color-match/index.html
# - math-practice-drills/index.html
# - music-theory-trainer/index.html
# - tiny-kanban/index.html
```
